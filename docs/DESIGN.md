# Visual Design System (DESIGN.md)

本ファイルは、AIエージェントがUIコード（HTML, CSS, React, など）を生成する際に参照するデザイン仕様書です。UIを構築する際は、必ずこのルールに従ってください。

> 参考サイト（ALBATROSS／DIMENSION）の解析結果をもとに、テンプレートの各トークンを具体値に置き換えています。両者の共通言語である「モノトーン基調＋写真主体＋タイポグラフィで魅せる」を軸に統一しました。

## 1. トーン＆マナー
* **ブランドイメージ:** ミニマル、洗練、本格的（装飾を削ぎ落としたコーポレート／クリエイティブ）
* **コアバリュー:** 写真とタイポグラフィの力で語ること。数字・実績・世界観を大胆なスケール感で見せ、説得力を持たせる

## 2. カラーパレット (Colors)
指定された役割（トークン）に応じて、以下のカラーコードを厳密に使用してください。
* **Primary (ブランドカラー):** `#111111` (漆黒。見出し・CTA・キーラインに使用)
* **Secondary (アクセント):** `#E8432E` (深みのあるレッド。ここぞという箇所にのみ局所使用し、多用しない)
* **Background (背景／ライトセクション):** `#F5F5F0` (ざらついた質感のオフホワイト)
* **Background Dark (背景／ダークセクション・追加):** `#0D0D0D` (暗転セクション用。ライトとダークを交互に重ねてリズムを作る)
* **Text Main (本文テキスト):** `#111111` (ライト面) / `#FFFFFF` (ダーク面)
* **Text Muted (薄いテキスト):** `#6E6E6E`
* **Border (境界線):** `#DADADA`

## 3. タイポグラフィ (Typography)
* **フォントファミリー (日本語):** `"Noto Sans JP", "Hiragino Sans", sans-serif`
* **フォントファミリー (英数字 本文):** `"Inter", system-ui, -apple-system, sans-serif`
* **フォントファミリー (見出し・ロゴ強調／追加):** `"Anton", "Oswald", sans-serif` — 極太コンデンス、オールキャップスでインパクトを出す用途に限定使用
* **ベースフォントサイズ:** `16px` (1rem)
* **見出し 1 (h1):** `4rem` (64px), `line-height: 1.1`, 極太, `letter-spacing: -0.02em`, オールキャップス推奨
* **見出し 2 (h2):** `2rem` (32px), `line-height: 1.2`, 太字
* **本文 (p):** `1rem` (16px), `line-height: 1.8`（日本語の可読性を優先しテンプレートより広めに設定）

## 4. スペースとレイアウト (Spacing)
余白や配置は、以下の8pxグリッドシステム（ベースは4px）を基準に設定してください。
* `px` (Padding/Margin): `4px`
* `spacing-1` (最小の余白): `8px`
* `spacing-2` (標準的な余白): `16px`
* `spacing-3` (セクション間の余白): `32px`
* `spacing-4` (大きな余白): `64px`
* `spacing-5` (ヒーロー・フルブリードセクション用／追加): `128px`
* **レイアウト方式:** CSS Flexbox または CSS Grid を優先的に使用すること。フルブリード（100vw）の写真セクションを許容する。

## 5. コンポーネントスタイル (Components)
* **ボタン (Button / Primary):**
  * 角丸 (border-radius): `999px`（完全角丸のピル形状）
  * パディング: 縦 `14px`, 横 `32px`
  * シャドウ: `none`
  * ホバー時のエフェクト: 背景色を少し暗くし、`transform: translateY(-1px)`を適用
* **ボタン (Button / Sharp・追加):**
  * 角丸 (border-radius): `0px`（黒背景・白文字のシャープな矩形。フォーム送信等の主張を抑えたい箇所に使用）
* **カード (Card):**
  * 背景: `#FFFFFF`
  * 角丸 (border-radius): `4px`（控えめな角丸）
  * 境界線: `1px solid [Border Color]`
  * 影 (box-shadow): `none`（参考サイトは影をほぼ使わずフラットな階層表現のため）
* **タグバッジ (Tag Badge／追加):**
  * 背景: `#EDEDED`
  * 角丸 (border-radius): `999px`
  * パディング: `4px 12px`
  * フォントサイズ: `12px`, `letter-spacing: 0.05em`
* **リスト行 / アコーディオン行 (List Row／追加):**
  * 構成: タグバッジ＋日付＋見出しテキスト＋右端シェブロンアイコン
  * 区切り: `1px solid [Border Color]` の下線のみ（カード化・背景色なし）
  * ホバー: 背景をごく薄くグレー化、シェブロンをアニメーションで開閉
  * 用途: お知らせ一覧・ニュース一覧等の反復リスト
* **仕様テーブル (Spec Table／追加):**
  * 構成: `ラベル：値` を2カラム（左右2グループ）で並べる定義リスト形式
  * ラベル幅は固定（例: 2〜3文字分の日本語ラベル）、値は可変幅
  * セル間は罫線なし、行間で余白のみ区切る
  * 用途: イベント詳細（日程／時間／チケット・会場／料金など）
* **統計数値 (Stat Highlight／追加):**
  * 単位ラベル（例: `IPO`）＋極太の大型数字＋助数詞（例: `社`）を横並びで配置
  * 数字部分のみ突出して大きく（本文比 5〜7倍程度）、実績・信頼性を強調する用途に限定使用

## 6. レスポンシブ振る舞い (Responsive)
* **モバイルファースト**で設計すること。
* **ブレイクポイント:**
  * スマホ (Mobile): `~ 639px`
  * タブレット (Tablet): `640px ~ 1023px`
  * デスクトップ (Desktop): `1024px ~`
* 横スクロールギャラリーやフルブリードのヒーローセクションは、モバイルでのタッチスワイプ操作に対応すること（追加）。

## 7. アクセシビリティ (Accessibility)
* すべてのテキスト（特に警告やエラーメッセージ）は、背景色とのコントラスト比を `4.5:1` 以上にすること。
* 画像には必ず `alt` 属性を記述すること。
* ライト／ダークセクションが切り替わる構成のため、切り替え直後の本文でもコントラスト比を維持すること（追加）。

## 8. エージェントプロンプトガイド (Agent Prompt)
AIエージェントへの指示です。コードを生成する際は、以下のルールを遵守してください。
1. 上記のトークン（変数名またはカラーコード）をハードコードせず、可能な限りCSS変数またはTailwindのクラスを用いて表現してください。
2. 日本語が不自然にならないよう、文字間隔（`letter-spacing`）や行間を適切に調整してください。
3. 未知のデザイン要素を生成する場合は、事前にユーザーに質問するか、このデザインシステムに準拠した形で提案してください。
4. 写真素材はグレースケールまたは自然光の実写を優先し、過度な装飾・イラスト・派手なアイコンは避けること（追加）。
   * **例外（美容室サイト向け）:** スタイル写真・スタッフ写真は訴求力を優先し、自然な発色のカラー写真を使用する（グレースケール化しない）。それ以外の背景・装飾方針は本デザインシステムを踏襲する。

## 9. ページレイアウトパターン (Page Layout Patterns／追加)
下層ページの解析により判明した、単一コンポーネントでは表現しきれないページ単位のレイアウトパターンです。

* **ウォーターマーク・ヒーロー:**
  * ダーク背景の本文ページ（例: Biographyのようなテキスト中心ページ）で、背景に極薄い白文字（opacity 5〜10%程度）でブランド名やキーワードを巨大表示し、その手前に本文を重ねる。
  * 本文は2〜3カラム相当の幅に収め、行間を広めに取り読みやすさを確保する。
* **分割レイアウト（左テキスト・右データ）:**
  * 左半分＝見出し＋説明文、右半分＝統計数値（Stat Highlight）やケーススタディの3カラムリストを配置する2カラム構成。
  * コーポレート系のトップ〜Aboutセクションに使用。
* **横スクロールギャラリー:**
  * カード（画像＋日付＋タイトル）を横一列に並べ、画面幅を超える分は横スクロールで見せる。左右に矢印ナビを添える。
  * 用途: 作品一覧・実績一覧等、時系列で並ぶビジュアルコンテンツ。
* **フィーチャー＋グリッド記事リスト:**
  * 最新1件は大型カード（画像大＋見出し＋抜粋文＋日付／タグ）で目立たせ、それ以降は3カラムグリッドの小型カード（日付＋タグ＋見出しのみ）で一覧化する。
  * 用途: ニュース・お知らせ一覧ページ。
* **縦型スクロールインジケーター（固定ナビ）:**
  * 画面右端に縦に固定表示。現在のセクション名（縦書き/回転テキスト）＋短い横線のドットリスト＋下部に「SCROLL」ラベルを配置。
  * 全ページ共通で表示し、現在地をユーザーに常時提示する。
* **顔写真グリッド:**
  * 正方形〜縦長の顔写真を隙間なく並べたグリッド（4〜6列）。氏名・役職はキャプションとして写真外またはホバー時に表示。
  * 用途: チーム／パートナー紹介ページ。

## 10. サイト構成マッピング（対象: 美容室）
参考サイト（ALBATROSS／DIMENSION）はデザイン言語抽出のための例であり、実際の制作対象は美容室サイトです。以下、必要コンテンツを上記デザインシステムのコンポーネント／パターンにマッピングします。

* **ナビゲーション構成:** `スタッフ / メニュー / クーポン / コンセプト / アクセス / 予約`（予約は目立たせるため右端にButton Primaryとして配置）
* **スタッフ:** 顔写真グリッド（4〜6列）を使用。写真はカラー（グレースケール化しない、8章の例外を参照）。キャプションに氏名・役職・得意メニューを表示。
* **メニュー:** 仕様テーブル（Spec Table）を使用。施術名をラベル、価格・所要時間を値として整理。カテゴリ（カット／カラー／パーマ等）ごとにセクション分割。
* **クーポン:** カード（Card）＋タグバッジを使用。割引率・有効期限をタグバッジで強調し、カード下部にButton Primary（例:「このクーポンを使う」）を配置。
* **コンセプト:** ウォーターマーク・ヒーロー、または分割レイアウト（左テキスト・右写真）を使用。ブランドストーリーを大型タイポグラフィ＋写真で表現。
* **アクセス:** 仕様テーブル（住所／最寄駅／営業時間／定休日をラベル：値で整理）＋地図埋め込み。
* **予約:** Contact型フォーム（お名前・電話番号・希望日時・メニュー選択等）＋Button Primary。日時選択が必要な場合は、カレンダーUIを新規コンポーネントとして追加検討する。

## 11. モバイル特有のUIパターン (Mobile Patterns／追加)
モバイルスクリーンショットの解析により判明した、デスクトップとは異なるモバイル固有の挙動・レイアウトです。

* **モバイルヘッダー:**
  * フルナビゲーションは非表示にし、右上に「CONTACT」ピルボタン＋円形の「MENU」ボタン（ハンバーガーの代わりにテキストラベル）の2点のみを常設表示する。
  * タップでMENUボタンからフルナビゲーション（ドロワー/オーバーレイ）を展開する想定。
* **グリッドの縮退:**
  * デスクトップで4〜6列だった顔写真グリッド（スタッフ／パートナー）は、モバイルでは2列グリッドに変更する。
* **ピーク・カルーセル（隣のカードが覗くスワイプ）:**
  * デスクトップの分割パネル（ポートフォリオ等）は、モバイルでは中央カードを大きく見せつつ左右のカードを少しだけ覗かせるスワイプカルーセルに変更する。ヘッダー直下にドットインジケーターを表示。
  * 用途: ポートフォリオ／実績紹介の横断ブラウジング。
* **横スクロールタブ（下線ハイライト）:**
  * デスクトップでカード横並びだったコンテンツ（Investee's Insights等）は、モバイルでは人物名を横スクロール可能なタブリストに変換し、選択中のタブのみ下線で強調、非選択タブはText Mutedで表示する。
* **フッターの1カラム縦積み:**
  * デスクトップの3カラム構成（ロゴ／リンク一覧／ポリシー）は、モバイルではロゴ→SNSアイコン行→リンク一覧（縦積み）→ポリシーの順に完全1カラムで積み上げる。
* **フローティングボタンの重なり許容:**
  * 「トップに戻る」等の固定フローティングボタンは、セクションの境界（明暗の切り替わり位置）に一部重なった状態で表示されることを許容する。次セクションのコンテンツより手前（z-indexで最前面）に固定する。
